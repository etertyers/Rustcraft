# M72 native perf gate (against v1.5.0, same session)

Measured as Kenzo asked for M71–M73: v1.5.0 (`2a88c35`), M72 (`763c322`) and M73 (`4c8b48b`) each built in a clean worktree and measured back to back in one session on the same Mac (display at 60 Hz, so not comparable with the fixed 120 Hz `docs/perf/baseline.json`; Kenzo will do the clean gate run there before merging). `--perf-test --runs 3`, then `cargo bench` for each.

| Measure | v1.5.0 | M72 | M73 |
|---|---|---|---|
| average_fps | 82.80 (spread 6.3%) | 81.45 (4.3%) | 81.74 (2.0%) |
| one_percent_low_fps | 48.95 | 48.47 | 48.74 |
| worst_frame_ms | 39.03 | 31.48 | 29.93 |
| chunk_generation_ms | 7.91 | 7.98 | 7.93 |
| light_mesh_ms | 8.32 | 8.09 | 7.91 |
| memory_mib | 716.5 | 662.9 | 708.5 |

| Bench | v1.5.0 | M72 | M73 |
|---|---|---|---|
| generate a chunk | 2.688 ms | +1.2% | +0.8% |
| generate a nether chunk | 1.397 ms | +0.1% | -0.4% |
| generate an end chunk | 34.712 µs | +1.2% | +2.1% |
| light a chunk | 1.171 ms | +5.5% | +5.2% |
| mesh a chunk | 2.083 ms | -10.1% | -10.1% |

Result: **not clearly worse than v1.5.0 beyond its run-to-run spread** (all within 1.6% on frame rate; the light bench's +5% and the mesh bench's -10% are the same noise pair seen in M71 and none of these milestones touches lighting or meshing). Golden hashes unchanged; `tests/vanilla_reference` passes.

M72's native changes are the chunk manager's single-thread mode (never used natively, which has worker threads), the new `platform` and `net::worker` modules, and the world zip code.
