# M25 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [40, 102, -636], 462 chunks loaded, 194 drawn.

| Measure | Value |
|---|---|
| Average FPS | 147 |
| 1% low FPS | 81 |
| Worst frame | 23.6 ms |
| Frames over 33 ms / 50 ms | 0 / 0 (of 8822) |
| Chunks generated or loaded | 1365 (avg 3.59 ms each, on worker threads) |
| Chunks lit and meshed | 1469 (avg 4.41 ms each, on worker threads) |
| Memory (resident) | 191 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The same Overworld flight as M24's: average FPS 147 → 147, 1% low 79 → 81, no frame over 33 ms (M24 had seven). Nothing in M25 touches the Overworld's frame; the Nether's structures are generated on the worker threads.

Nether chunks over a structure (`cargo test --release structure_chunk_time -- --ignored`, one fresh thread so the first chunk lays the whole structure out): a fortress's 49 chunks average **1.75 ms**, a bastion's 9 average **1.37 ms**, against 1.39 ms for a plain Nether chunk.
