# M15 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [0, 102, -708], 462 chunks loaded, 180 drawn.

| Measure | Value |
|---|---|
| Average FPS | 189 |
| 1% low FPS | 77 |
| Worst frame | 41.8 ms |
| Frames over 33 ms / 50 ms | 6 / 0 (of 11319) |
| Chunks generated or loaded | 1365 (avg 4.12 ms each, on worker threads) |
| Chunks lit and meshed | 2141 (avg 5.27 ms each, on worker threads) |
| Memory (resident) | 170 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

Textures: Kenzo's defaults, no pack selected. For comparison, the `--bench 8` flight with a pack selected (render distance 9, off screen) averaged 199 fps with Ashen (16×), 223 fps with Prime's HD (32×) and 202 fps with both, against 210 fps with none.
