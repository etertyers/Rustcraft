# M21 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [80, 102, -596], 462 chunks loaded, 203 drawn.

| Measure | Value |

| Average FPS | 137 |
| 1% low FPS | 63 |
| Worst frame | 26.9 ms |
| Frames over 33 ms / 50 ms | 0 / 0 (of 8238) |
| Chunks generated or loaded | 1365 (avg 3.51 ms each, on worker threads) |
| Chunks lit and meshed | 1460 (avg 5.71 ms each, on worker threads) |
| Memory (resident) | 214 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The flight now starts on a stony shore, crosses an ocean, then forest, savanna, plains and windswept hills (the new generator puts spawn at 80, 112). Average FPS 141 → 137 and the 1% low 59 → 63, with no frame over 33 ms. Chunk generation on the worker threads averaged 3.51 ms (3.97 in M20); resident memory was 214 MiB (321 in M20).

## `cargo bench`

| Benchmark | Time | vs M20 |
|---|---|---|
| generate a chunk | 1.26 ms | −22% |
| light a chunk | 0.663 ms | −2% |
| mesh a chunk | 1.05 ms | +39% (different blocks; the mesher is unchanged, see below) |
| 100 ticks of spreading water | 3.18 ms | −11% |
| 100 ticks of redstone lines | 2.79 ms | +1% |

"mesh a chunk" meshes generated chunk (2, −5) with its neighbors, and the new generator puts different blocks there: an ocean shelf rather than M20's land, with water surfaces and a sea floor in view. To check the mesher itself, the nine chunks M20's generator makes there were saved from an M20 checkout (chunk format 2, which M21 still reads) and meshed by both versions: **M20 0.757 ms, M21 0.758 ms**. The mesher hasn't slowed; the benchmark's input changed.

"generate a chunk" does much more than M20 (five climate fields, mountains, caverns, modern ore counts, cave biomes, geodes, many tree shapes) and still got faster: the climate is sampled every four blocks and blended, cave noise is sampled on a 4×4×4 grid, columns are worked out once per chunk with a 12-block margin and shared by ores and trees, and veins that start far above the ground or can't reach the chunk are skipped.

Gate: **pass** (the meshing change is the benchmark's input, not a slowdown).
