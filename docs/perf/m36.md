# M36 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [40, 102, -636], 441 chunks loaded, 222 drawn.

| Measure | Value |
|---|---|
| Average FPS | 140 |
| 1% low FPS | 61 |
| Worst frame | 36.0 ms |
| Frames over 33 ms / 50 ms | 1 / 0 (of 8401) |
| Chunks generated or loaded | 1344 (avg 6.15 ms each, on worker threads) |
| Chunks lit and meshed | 3751 (avg 11.41 ms each, on worker threads) |
| Memory (resident) | 311 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The flight now runs through the in-process server: the server generates and lights chunks, and this client lights and meshes its own copy. "Chunks generated or loaded" is the server's work; "lit and meshed" is the client's.
