Measured on Macmini9,1 (Apple M1); ended at [0, 102, -708], 462 chunks loaded, 203 drawn.

| Measure | Value |
|---|---|
| Average FPS | 159 |
| 1% low FPS | 65 |
| Worst frame | 43.2 ms |

| Chunks lit and meshed | 2127 (avg 5.32 ms each, on worker threads) |
| Memory (resident) | 316 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The flight is the same as before; redstone, hoppers and carts add per-tick work only where those blocks exist (the chunk-load scan now also looks for redstone parts). Average FPS 175 → 159 and resident memory 172 → 316 MiB are larger than usual run-to-run differences; the flight drew 203 chunks against 187, and memory wasn't investigated further. Still well inside the gate.
