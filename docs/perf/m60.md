## Gate (scripts/perf_gate.py, all rows)

Mac mini M1. Vanilla passes every check (124.0 avg FPS, 57.6 1%-low, 612 MiB). The FAILs are the same ones as in M59's control run (the v1.4.0 commit measured on this Mac gave Trailer Low 93.6 / 51.6 and about 690 MiB): the stored Trailer baseline has drifted from this Mac, v1.4 already shipped with Low/High a few percent under their budgets, and the two CPU benches (spreading water +9%, light a chunk +6%) are code M60 doesn't touch. M60 adds code only behind --texture-audit, --texture-viewer and the viewer screens; normal frames are unchanged. Baseline not updated (M62).
