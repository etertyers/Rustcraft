# M16 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [0, 102, -708], 462 chunks loaded, 180 drawn.

| Measure | Value |
|---|---|
| Average FPS | 180 |
| 1% low FPS | 82 |
| Worst frame | 42.9 ms |
| Frames over 33 ms / 50 ms | 7 / 0 (of 10773) |
| Chunks generated or loaded | 1365 (avg 4.07 ms each, on worker threads) |
| Chunks lit and meshed | 2077 (avg 5.23 ms each, on worker threads) |
| Memory (resident) | 170 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The flight draws the bare first-person arm in its own pass. For comparison, 10-second `--bench` flights at render distance 9 averaged 188 fps behind the player (F5 once) and 181 fps in front of them, against 205 in first person.
