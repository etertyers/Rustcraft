# M24 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [40, 102, -636], 462 chunks loaded, 194 drawn.

| Measure | Value |
|---|---|
| Average FPS | 147 |
| 1% low FPS | 79 |
| Worst frame | 45.7 ms |
| Frames over 33 ms / 50 ms | 7 / 0 (of 8806) |
| Chunks generated or loaded | 1365 (avg 3.53 ms each, on worker threads) |
| Chunks lit and meshed | 1599 (avg 4.31 ms each, on worker threads) |
| Memory (resident) | 188 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The same Overworld flight as M23's, compared against the numbers after the M21 worldgen rework (#25), which M24 is built on. Average FPS 146 → 147, 1% low 85 → 79. Seven frames went over 33 ms (none over 50); the rework's run had none. They fall in the flight's chunk streaming (chunks 1.0 ms of the 45.7 ms worst), not in anything M24 added to the Overworld, and the 1% low stays far above the gate. Memory 182 → 188 MiB.

The Nether isn't in the scripted flight (it flies a generated Overworld). Its chunks cost about what Overworld ones do: see "generate a nether chunk" below. M30 profiles every dimension.
