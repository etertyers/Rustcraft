# M23 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [80, 102, -596], 462 chunks loaded, 203 drawn.

| Measure | Value |
|---|---|
| Average FPS | 129 |
| 1% low FPS | 59 |
| Worst frame | 24.7 ms |
| Frames over 33 ms / 50 ms | 0 / 0 (of 7756) |
| Chunks generated or loaded | 1365 (avg 4.09 ms each, on worker threads) |
| Chunks lit and meshed | 1799 (avg 5.70 ms each, on worker threads) |
| Memory (resident) | 234 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The same flight as M22's, now passing over structures (dungeons and a mineshaft underground on this seed). Average FPS 134 → 129, 1% low 63 → 59, no frame over 33 ms. Chunk generation on the worker threads averaged 4.09 ms (3.44 in M22): each chunk now finds the structures reaching it and writes its part, and laying out a new village or stronghold costs a few milliseconds once per worker thread. Resident memory was 234 MiB (206 in M22).
