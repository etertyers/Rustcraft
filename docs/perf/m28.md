The same Overworld flight as M27's: average FPS 146 → 140, 1% low 80 → 84, no frame over 33 ms (M27's first run measured 141, so the spread is the M1's, about ±3%). Armor slots, the elytra and the shulker bullets tick only when they exist; the inventory has four more slots.
