# M29 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [40, 102, -636], 462 chunks loaded, 194 drawn.

| Measure | Value |
|---|---|
| Average FPS | 143 |
| 1% low FPS | 76 |
| Worst frame | 22.1 ms |
| Frames over 33 ms / 50 ms | 0 / 0 (of 8605) |
| Chunks generated or loaded | 1365 (avg 3.66 ms each, on worker threads) |
| Chunks lit and meshed | 1473 (avg 4.55 ms each, on worker threads) |
| Memory (resident) | 196 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The same Overworld flight as M28's: average FPS 140 → 143, 1% low 84 → 76, no frame over 33 ms (the M1's spread is about ±5% on the 1% low across these runs). The new per-tick work is the advancements' look at the inventory every ten ticks and at the biome and structures every twenty, and the toast list.
