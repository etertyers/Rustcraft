# M71 native perf gate (measured against v1.5.0 in the same session)

Per Kenzo's rule for M71–M73: v1.5.0 (`2a88c35`) and the milestone commit (`9420565`) were each built in a clean worktree and measured back to back on the same Mac (display at 60 Hz), `--perf-test --runs 3`, then `cargo bench` for each. The fixed `docs/perf/baseline.json` was captured on a 120 Hz setup; Kenzo will do the clean gate run there before merging.

| Measure | v1.5.0 | M71 | Change |
|---|---|---|---|
| average_fps | 108.70 (run spread 16.5%) | 109.43 (18.0%) | +0.7% |
| one_percent_low_fps | 52.24 | 54.75 | +4.8% |
| worst_frame_ms | 31.30 | 36.05 | within spread |
| bench: generate a chunk | 2.681 ms | 2.823 ms | +5.3% |
| bench: generate a nether chunk | 1.397 ms | 1.405 ms | +0.6% |
| bench: generate an end chunk | 34.7 µs | 34.6 µs | -0.1% |
| bench: light a chunk | 1.172 ms | 1.243 ms | +6.0% |
| bench: mesh a chunk | 2.081 ms | 1.908 ms | -8.3% |
| bench: spreading water / redstone (first row) | 2.922 ms | 2.930 ms | +0.3% |

Result: **not clearly worse than v1.5.0 beyond its run-to-run spread** (the bench moves go both ways; M71 doesn't touch generation, light or meshing code). Golden hashes: unchanged. `tests/vanilla_reference` (Vanilla pixel identity; M71 changed `textureSample` to `textureSampleLevel(..., 0.0)` for the single-mip nearest textures): passes.
