# M27 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [40, 102, -636], 462 chunks loaded, 194 drawn.

| Measure | Value |
|---|---|
| Average FPS | 146 |
| 1% low FPS | 80 |
| Worst frame | 20.9 ms |
| Frames over 33 ms / 50 ms | 0 / 0 (of 8788) |
| Chunks generated or loaded | 1365 (avg 3.58 ms each, on worker threads) |
| Chunks lit and meshed | 1467 (avg 4.40 ms each, on worker threads) |
| Memory (resident) | 197 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The same Overworld flight as M26's: average FPS 148 → 146, 1% low 81 → 80, no frame over 33 ms. A first run measured 141 average and 80 for the 1% low; the M1's run-to-run spread is about ±3%, and nothing the flight touches changed. The new End code only runs in the End: eyes, crystals, the dragon and its clouds are empty lists elsewhere, and empty meshes aren't uploaded.
