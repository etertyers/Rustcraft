# M20 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [0, 102, -708], 462 chunks loaded, 203 drawn.

| Measure | Value |
|---|---|
| Average FPS | 141 |
| 1% low FPS | 59 |
| Worst frame | 51.7 ms |
| Frames over 33 ms / 50 ms | 20 / 2 (of 8466) |
| Chunks generated or loaded | 1365 (avg 3.97 ms each, on worker threads) |
| Chunks lit and meshed | 2242 (avg 5.12 ms each, on worker threads) |
| Memory (resident) | 321 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The flight now meets many more animals (cows, sheep, chickens, horses, rabbits, bees) and the mob thinking, drawing and spawning for 25 kinds. Average FPS 159 → 141 and the 1% low 65 → 59 (worst frame 51.7 ms, two over 50 ms) are a real cost, still well inside the gate; sensing is limited to mobs that use it, which kept it from being worse.
