# M22 performance

`cargo run --release -- --perf-test`: seed 20111118, a 60 s flight north at 10.9 blocks/s and feet height 100, render distance 9, 1920×1080, vsync off, after 5 s of warm-up.

Measured on Macmini9,1 (Apple M1); ended at [80, 102, -596], 462 chunks loaded, 203 drawn.

| Measure | Value |
|---|---|
| Average FPS | 134 |
| 1% low FPS | 63 |
| Worst frame | 33.9 ms |
| Frames over 33 ms / 50 ms | 1 / 0 (of 8048) |
| Chunks generated or loaded | 1365 (avg 3.44 ms each, on worker threads) |
| Chunks lit and meshed | 1457 (avg 5.42 ms each, on worker threads) |
| Memory (resident) | 206 MiB |

Gate (average ≥ 60, 1% low ≥ 40): **pass**

The flight is the same as M21's. Average FPS 137 → 134 and the 1% low 63 → 63, with one frame over 33 ms (33.9 ms). Experience orbs, the glint flag in the shader and the extra bind group cost nothing measurable with no enchanted items or orbs in view. Resident memory was 206 MiB (214 in M21).
